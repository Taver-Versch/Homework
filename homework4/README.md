Homework Instructions
Scenario
You are the vault master of an ancient dungeon. Your task is to create a web-based system for adventurers to:

Add artifacts discovered in the dungeon.
Search for artifacts by name.
Remove artifacts from the vault.
View all artifacts in the vault sorted by name or rarity.
Artifacts have the following properties:

Name – The artifact’s unique name (e.g., Sword of Ember).
Type – Type of artifact (e.g., Weapon, Armor, Potion).
Rarity – Rarity of the artifact (e.g., Common, Rare, Legendary).
Power Level – Numeric value representing the artifact’s strength.
 

Requirements
Functional Requirements
Your application must include:

Add Artifact
Input fields for name, type, rarity, and power level.
A button to add the artifact to the vault.
Search Artifact
Input field to search by name.
Display artifact details if found, or a “Not Found” message.
Remove Artifact
Remove an artifact by name.
Handle cases where the artifact does not exist.
View Vault
Display all artifacts in a list, sorted alphabetically by name or by rarity.
 

Design Requirements
The UI must resemble a retro 90s dungeon-crawler interface, e.g.,
Dark stone or metal panels.
Beveled buttons and frames.
Pixel or retro-style readable fonts.
The UI should be responsive and user-friendly.
 

Optional Bonus
Custom Sorting & Filtering (5 points)
Add filtering by type or rarity.
Add sorting buttons for name, rarity, or power level.
